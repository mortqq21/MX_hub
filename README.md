## ⚡ Quick Loadstring

Copy and paste the following script into your Roblox executor (**Solara, Wave, Delta, CodeX, Hydrogen, Fluxus**):

```lua

```

> **Note**: Replace `USERNAME` and `REPOSITORY` with your GitHub username and repository name after uploading!
